# Top 5 Interview Algorithms for Freshers

A beginner-friendly lecture folder. Each file explains one algorithm in
simple steps, then shows a working Python implementation you can run.

## The 5 algorithms

Each algorithm has a runnable `.py` file AND a full explanation doc in `docs/`.

| # | Code | Explanation doc | Algorithm | Why interviewers ask it |
|---|------|-----------------|-----------|------------------------|
| 1 | `01_linear_and_binary_search.py` | `docs/01_search_explained.md` | Linear & Binary Search | Searching is the most basic task; binary search teaches divide & conquer |
| 2 | `02_bubble_sort.py` | `docs/02_bubble_sort_explained.md` | Bubble Sort | Simplest sorting algorithm; gateway to merge/quick sort |
| 3 | `03_two_sum_hashmap.py` | `docs/03_two_sum_explained.md` | Two Sum (hash map) | The most-asked fresher question ever; teaches hash maps |
| 4 | `04_palindrome_two_pointers.py` | `docs/04_palindrome_explained.md` | Palindrome Check (two pointers) | Teaches the two-pointer technique used in many problems |
| 5 | `05_recursion_fibonacci.py` | `docs/05_recursion_explained.md` | Recursion (Factorial & Fibonacci) | Tests whether you understand functions calling themselves |

## How to study each algorithm

1. Read the explanation doc in `docs/` — idea, analogy, steps, trace, complexity, follow-up questions.
2. Read the code — every line is commented.
3. Run it: `python <file>` and watch the output.
4. Try changing the input data and predict the output before running.

## Typical interview follow-ups

- What is the time complexity? (Big-O)
- Can you do it without extra memory?
- What happens on an empty input / one element / duplicates?
